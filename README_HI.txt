PINK NOVA Android Project + Cloud APK Build

CLOUD SE APK BANANE KE STEPS (mobile browser se bhi):
1. GitHub.com par sign in karein aur New repository banayein (naam: PinkNova).
2. Is ZIP ko extract karein. Extracted folder ke ANDAR ki saari files/folders (including .github folder) repository mein upload karein. .github folder ko bhi upload karna zaroori hai.
3. Repository ke Actions tab mein jaayein.
4. "Build Pink Nova APK" workflow select karke Run workflow dabayein. Main branch par files push karne se bhi build automatic start hoga.
5. Build complete hone par workflow run kholein; Artifacts section mein PinkNova-debug-APK download karein.
6. ZIP extract karke app-debug.apk install karein. Android agar pooche to browser/files app ko Install unknown apps permission dein.
